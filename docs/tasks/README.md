## 命名规则

- 大任务：英文字母加任务名，例如 `Q邮箱绑定与验证`。
- 大任务计划：字母加 `00`，例如 `Q00_执行计划.md`。
- 小任务：同一字母加两位序号和具体内容，例如 `Q01_定义邮箱身份状态与接口契约.md`。
- 小任务必须放在所属大任务目录内，不能直接散落在 `未完成` 或 `已完成` 根目录。

## 状态流转

1. 新任务先进入 `未完成/字母任务名/`，任务文件状态写为“未完成”。
2. 完成一个小任务后，将该文件状态改为“已完成”，但仍保留在所属大任务目录内。
3. 只有大任务下所有小任务通过验收、代码合并且 `字母00` 完成定义满足后，才把整个大任务目录移动到 `已完成/`。
4. 不允许只因文档写完就将开发任务标记为已完成。
