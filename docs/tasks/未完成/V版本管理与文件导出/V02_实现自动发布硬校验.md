# V02 实现自动发布硬校验

> 状态：未完成
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 校验必需章节和报告身份信息。
2. 校验正文数值与结构化指标结果一致。
3. 校验比较周期完整性和时间范围一致性。
4. 校验结论具有证据引用。
5. 校验原因措辞与证据状态。
6. 校验接收范围和敏感字段处理结果。
7. 输出机器可读 `validation_json`，包含规则编号、等级、结果和说明。

验收：任一硬规则失败都会阻止正常周报自动发布。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
