# V00 版本管理与文件导出执行计划

> 状态：未完成
>
> 大任务：`V版本管理与文件导出`
> 目标：建立自动发布前的确定性校验、不可变版本规则，以及与站内版本一致的 PDF/Excel 文件生成和鉴权下载。
> 前置依赖：M 业务数据模型与迁移
> 协作依赖：R 调用校验器并发布；E 使用 PDF；U 使用下载 API

本任务负责结构化报告校验、文件生成、文件存储元数据和下载鉴权。不负责报告内容的 Agent 生成、消息创建或邮件发送。

## 五、风险与回滚

- 风险：服务端中文字体或图表渲染不一致。缓解：固定运行镜像、字体包和视觉回归样例。
- 风险：Excel 包含越权明细。缓解：导出查询复用权限服务，不使用前端已加载数据拼文件。
- 风险：文件存储失效。缓解：文件状态与报告状态分离，支持重新生成。
- 回滚：可以临时关闭新文件任务并保留旧 HTML 预览，但不得把浏览器打印继续宣称为正式服务端 PDF。

## 六、完成定义

- V01～V09 全部完成。
- 自动发布硬校验可阻止错误报告。
- 已发布版本不可变且可建立替代关系。
- PDF 与 Excel 均由服务端生成并受鉴权保护。
- PDF 具有经过批准的精美布局，包含业务图片/洞察主图、真实图表和规范表格。
- PDF 与邮件引用的版本一致。
- 文件失败可重试且不影响站内发布。
