# V06 实现 Excel 明细导出

> 状态：未完成
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 创建“指标概览、异常明细、行动建议、数据来源与口径”工作表。
2. 数值使用真实数值单元格，日期使用日期类型，避免全部写成文本。
3. 每个工作表包含报告周期、版本和导出说明。
4. 仅导出已授权范围的数据。
5. 对空数据、长文本、大量异常明细和特殊字符进行测试。

验收：Excel 能被常用表格软件正常打开，内容与站内权限一致。

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。

- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
