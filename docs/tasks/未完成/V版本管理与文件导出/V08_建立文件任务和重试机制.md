# V08 建立文件任务和重试机制

> 状态：未完成
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 使用租约消费者领取 `report.version.published` Outbox 事件，并按业务键幂等确认。
2. PDF 与 Excel 独立排队、执行和重试。
3. 同版本同格式通过唯一约束去重。
4. 已成功文件默认复用，不重复渲染。
5. 失败记录错误分类和可重试性，超过上限进入可恢复死信状态。
6. PDF 成功与 `report.file.ready` Outbox 事件在同一事务写入，供 E 消费。
7. 测试领取后崩溃、文件写入后崩溃和重复事件，确保最终状态可恢复。

验收：PDF 失败不影响 Excel，文件失败不回滚报告发布，
进程崩溃不丢失文件任务或就绪事件。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
