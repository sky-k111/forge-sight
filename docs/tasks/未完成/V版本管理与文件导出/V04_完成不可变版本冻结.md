# V04 完成不可变版本冻结

> 状态：未完成
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 结构化正文、数据快照、校验结果、Agent 快照同时冻结。
2. 计算版本内容 SHA-256，后续文件记录该内容校验值。
3. 禁止更新已发布版本的内容字段。
4. 新版本建立替代关系，旧版本保留。
5. 编写服务级与数据库级防覆盖测试。

验收：已发布内容无法被原生成任务或普通更新接口修改。

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。

- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
