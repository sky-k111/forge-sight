# V01 定义结构化周报 schema

> 状态：实施完成，待合并
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 为报告身份、摘要、指标、趋势、异常、进展、建议、数据质量和附录定义版本化 schema。
2. 数值字段使用数值类型和单位，不只保存格式化字符串。
3. 每条重要结论保存证据引用和置信度。
4. schema 增加 `schema_version`，为未来升级保留转换器。
5. API 和文件生成均消费同一结构化内容。

验收：页面、PDF、Excel 不需要分别解析不同来源的数据。
