# V03 实现软校验与可信度计算

> 状态：实施完成，待合并
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 检查数据缺失、延迟、临时推导指标和局部章节失败。
2. 根据可解释规则计算章节及整份报告可信度。
3. 低可信度结论在正文和 PDF 中明确标识。
4. 严重数据不足时切换数据异常版模板。
5. 可信度算法版本化并写入报告版本。

验收：低质量数据不会被包装成高确定性结论。

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
