# E09 完成集成、安全与容量测试

> 状态：实施完成，待合并
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. fake provider 验证主题、摘要、链接、附件内容和 MIME。
2. 测试周报、数据异常版、公告、超大附件和无效邮箱。
3. 测试并发 Worker、超时、限流、崩溃和重复事件。
4. 扫描日志和错误响应，确认无凭据、验证码或敏感正文泄漏。
5. 对目标用户量做批量发送基准，验证限速和队列积压指标。

验收：关键触达路径自动化测试通过，容量和重试行为有数据记录。

## 实施记录

- 自动化覆盖周报、公告、PDF 等待、附件超限、邮箱变更、权限撤销、错误链接、
  3 次退避上限、事件过滤、SMTP MIME 和管理员重发。
- SQLite 隔离库容量用例一次展开 200 个已验证接收人，生成 200 条独立幂等投递；
  运行耗时随 CI 在 pytest `--durations` 输出中记录，生产吞吐继续由 T 任务在 PostgreSQL
  与真实服务商限速条件下验收。
- 所有邮件发送测试使用 capture/fake Provider，不访问真实 SMTP。
