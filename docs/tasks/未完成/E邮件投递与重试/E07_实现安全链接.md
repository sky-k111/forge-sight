# E07 实现安全链接

> 状态：实施完成，待合并
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. 链接使用 `PUBLIC_APP_URL` 和站内报告/公告路由。
2. 不在 URL 中包含邮箱、长期 token 或存储 URI。
3. 未登录时通过前端保存回跳地址，登录后仍由 API 做权限校验。
4. 链接构造统一处理反向代理前缀和 HTTPS。
5. 测试恶意 Host、路径注入和错误环境配置。

验收：复制链接给无权限用户无法获得内容。
