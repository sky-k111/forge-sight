# E01 定义邮件提供商接口与配置

> 状态：未完成
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. 定义 `send(message) -> provider_result` 抽象接口。
2. 支持纯文本与 HTML 正文、附件、超时和服务商消息 ID。
3. 配置项包含提供商、服务器、端口、TLS、账号、凭据、发件地址、发件名称和附件上限。
4. 生产日志不得打印认证头、密码或完整邮件正文。
5. 测试环境提供 fake provider，开发环境可选本地捕获服务。

验收：替换提供商不需要修改报告和公告业务服务。
