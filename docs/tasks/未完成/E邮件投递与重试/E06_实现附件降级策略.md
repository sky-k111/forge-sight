# E06 实现附件降级策略

> 状态：实施完成，待合并
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. PDF 未就绪时保持任务等待，不提前发送缺附件的正常周报邮件。
2. PDF 生成最终失败时记录阻断原因并允许文件任务修复后恢复。
3. PDF 超过提供商附件上限时发送摘要和安全链接，并标记 `attachment_omitted`。
4. 不自动改发 Excel，避免泄露大量明细。
5. 邮件正文明确说明附件省略原因。

验收：附件异常不会回滚站内报告，也不会静默声称附件已发送。

- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
