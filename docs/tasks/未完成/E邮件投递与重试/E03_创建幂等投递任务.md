# E03 创建幂等投递任务

> 状态：实施完成，待合并
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. 按 N 的当前契约，只领取统一的 `message.published` Outbox 事件，成功后确认，失败后退避重试。
2. 查询目标用户当前已验证邮箱，保存接收地址快照。
3. 使用 `message_id + user_id + channel` 作为周报与公告统一幂等边界；周报投递仍固定关联具体版本。
4. 邮箱未验证、用户停用或无权限时标记 `suppressed` 并记录原因。
5. 批量创建失败只影响对应用户。

验收：重复事件不会重复创建业务投递或重复发信，领取后进程崩溃可由其他 Worker 恢复。
