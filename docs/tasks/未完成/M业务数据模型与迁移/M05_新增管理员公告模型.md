# M05 新增管理员公告模型

> 状态：未完成
> 所属大任务：`M业务数据模型与迁移`
> 总体计划：[M00 执行计划](./M00_执行计划.md)

## 执行内容

1. 新增 `Announcement` 和必要的版本字段，保存正文、优先级、接收范围、置顶和有效期。
2. 状态支持草稿、已发布、已撤回、已过期。
3. 发布后正文不可直接改写；修订形成新版本或新公告记录。
4. 保存创建人、发布人、撤回人和对应时间。
5. 接收范围使用结构化 JSON，并保存规范化哈希用于审计。

验收：公告可以恢复发布当时的正文和接收范围。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
