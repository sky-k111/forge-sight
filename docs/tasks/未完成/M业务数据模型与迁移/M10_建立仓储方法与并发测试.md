# M10 建立仓储方法与并发测试

> 状态：未完成
> 所属大任务：`M业务数据模型与迁移`
> 总体计划：[M00 执行计划](./M00_执行计划.md)

## 执行内容

1. 提供按幂等键获取或创建报告、消息和投递的事务方法。
2. 提供原子冻结版本、切换当前版本和建立替代关系的方法。
3. 对并发调度、并发发布、Outbox 领取、并发消息创建和并发投递创建写测试。
4. 验证唯一约束冲突能够转换为业务幂等成功或明确错误。
5. 禁止服务层先查后写而没有数据库约束兜底。

验收：并发执行不会生成重复版本、消息或投递。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
