# W01 统一适配器架构与领域契约

> 状态：核心实现完成，真实数据库验收待 W04
>
> 目标：将连接、元数据、方言、限行和成本计划差异收口到可注册、可测试的 Adapter，保证 Agent 与业务服务不感知数据库驱动细节。

## 一、代码结构

```text
backend/app/gateway/
├── connectors/
│   ├── __init__.py
│   ├── base.py
│   ├── registry.py
│   ├── mysql.py
│   ├── postgresql.py
│   └── enterprise.py
├── executor.py
├── sql_validator.py
└── cost_guard.py
```

现有 `backend/app/gateway/adapters.py` 在迁移期保留兼容导出，内部委托给 Registry；调用方稳定后再删除旧分支逻辑。

## 二、核心类型

```python
@dataclass(frozen=True)
class AdapterCapabilities:
    schemas: bool = True
    comments: bool = True
    primary_keys: bool = True
    foreign_keys: bool = True
    explain: bool = True
    explain_cost: bool = True
    readonly_transaction: bool = True
    server_side_limit: bool = True


@dataclass(frozen=True)
class DataSourceTypeDescriptor:
    type: str
    label: str
    default_port: int
    fields: tuple[ConnectionField, ...]
    capabilities: AdapterCapabilities
    maturity: str  # verified / beta / unavailable


@dataclass(frozen=True)
class PhysicalTableRef:
    catalog: str | None
    schema: str
    name: str


@dataclass
class SchemaSnapshot:
    schemas: list[str]
    tables: list[TableMetadata]
    captured_at: datetime
    warnings: list[str]
```

适配器协议：

```python
class DatabaseAdapter(Protocol):
    type: str
    sqlglot_dialect: str
    descriptor: DataSourceTypeDescriptor

    def build_url(self, source: DataSource, secret: dict) -> str: ...
    def create_engine(self, source: DataSource, secret: dict) -> Engine: ...
    def configure_readonly(self, engine: Engine, source: DataSource) -> None: ...
    def test_connection(self, source: DataSource) -> ConnectionTestResult: ...

    def list_schemas(self, connection, source: DataSource) -> list[str]: ...
    def inspect_metadata(self, connection, source: DataSource) -> SchemaSnapshot: ...
    def preview_table(self, connection, table: PhysicalTableRef, limit: int) -> TableResult: ...

    def quote_identifier(self, value: str) -> str: ...
    def qualify_table(self, table: PhysicalTableRef) -> str: ...
    def apply_server_limit(self, sql: str, limit: int) -> str: ...
    def explain(self, connection, sql: str) -> ExplainResult: ...
    def dialect_prompt(self) -> str: ...
```

## 三、注册与发现

```python
ADAPTERS: dict[str, DatabaseAdapter] = {}

def register_adapter(adapter: DatabaseAdapter) -> None:
    if adapter.type in ADAPTERS:
        raise RuntimeError(f"重复数据源适配器：{adapter.type}")
    ADAPTERS[adapter.type] = adapter

def get_adapter(source_type: str) -> DatabaseAdapter:
    try:
        return ADAPTERS[source_type]
    except KeyError as exc:
        raise UnsupportedDataSourceError(source_type) from exc
```

`GET /api/datasources/types` 直接序列化 Adapter Descriptor。前端仅保留接口不可用时的降级文案，不把降级清单作为后端能力依据，避免“前端显示支持、后端实际不支持”。

## 四、资源身份与隔离

所有物理资产使用以下作用域：

```text
tenant_id + source_id + catalog + schema_name + object_name
```

当前版本可以让 `catalog` 为空，但字段必须预留。表、字段、关系、样例、语义文档、指标物理绑定、监控源契约和证据引用均应携带 `schema_name`。

禁止仅使用表名做白名单比较：

```python
# 错误
allowed_tables = {"orders"}

# 正确
allowed_tables = {
    PhysicalTableRef(catalog=None, schema="sales", name="orders")
}
```

未显式携带 Schema 的 SQL，只能在数据源配置恰好选择一个业务 Schema 时解析；选择多个 Schema 后，重复表名必须要求限定名或澄清。

## 五、统一执行边界

执行顺序固定为：

```text
检查租户和数据源权限
→ 获取 Adapter
→ 按 Adapter 方言解析 SQL AST
→ 验证单条只读语句
→ 验证 Schema/表白名单
→ Adapter 生成 EXPLAIN
→ 成本门控或明确降级
→ Adapter 添加服务端行数限制
→ 在只读连接上执行
→ 截断、类型归一化、脱敏
→ 写审计、产物和证据链
```

所有执行入口，包括 Agent、监控、周报、手工 SQL、建模数据集和即时预览，必须调用同一个 Gateway。禁止业务模块直接 `engine.execute()` 绕过校验。

## 六、连接池与配置更新

连接池缓存键：

```text
(tenant_id, source_id, connection_revision)
```

管理员修改主机、端口、数据库、Schema、用户名、密码或连接选项时，必须增加 `connection_revision` 并 dispose 旧池。只以 `source_id` 缓存会在密码或地址更新后继续复用旧连接。

连接必须设置：

- `pool_pre_ping`；
- 明确 connect timeout 和 query timeout；
- 可配置池大小和回收时间；
- 日志只记录数据源 ID 和错误分类，不记录密码或完整 DSN；
- 测试连接失败后释放对应连接池；
- 删除或停用数据源后立即释放连接池。

## 七、方言配置进入 Agent

Agent 状态只接收必要的能力描述：

```json
{
  "sourceType": "postgresql",
  "dialect": "postgres",
  "selectedSchemas": ["mes"],
  "identifierQuote": "double",
  "limitStyle": "limit",
  "supportsFullOuterJoin": true,
  "dateFunctions": {
    "monthBucket": "date_trunc('month', column)"
  }
}
```

不向 LLM 暴露主机、端口、账号、密码或 DSN。方言提示由 Adapter 生成，`agent/graph.py` 不再包含数据库类型分支。

## 八、验收标准

- MySQL/PostgreSQL 迁移到 Registry 后现有功能与测试不退化；
- 全仓不再新增 `if source.type == ...` 的方言分支，适配器内部除外；
- 数据源类型 API 与 Registry 同源；
- 所有查询入口走统一 Gateway；
- 资源身份包含 Schema；
- 连接配置更新可证明不会复用旧连接；
- Adapter 能力缺失以结构化状态返回，不得伪装成功。
