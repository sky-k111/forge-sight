# R03 执行数据与指标预检

> 状态：未完成
> 所属大任务：`R智能生成与自动发布`
> 总体计划：[R00 执行计划](./R00_执行计划.md)

## 执行内容

1. 检查数据源连接、模板启用状态、指标物理绑定和时间字段。
2. 检查本期与比较期是否完整。
3. 计算数据截止时间、覆盖率、缺失比例和延迟源。
4. 根据模板最低覆盖率判定正常生成或数据异常版周报。
5. 冻结本次使用的模板、指标和绑定版本。

验收：关键数据不可用时不会继续生成伪完整周报。

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。

- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
