1. 去除人工“待复核”作为新周报主流程的呈现。
2. 列表展示周期、版本、总体结论、严重异常数、数据完整度和发布时间。
3. 支持周期、报告类型、组织范围、异常等级和已读状态筛选。
4. 每行提供查看详情、下载 PDF 和下载 Excel。
5. 真实展示生成、校验、附件和投递状态，不使用假动画。

验收：列表能区分生成中、已发布、数据异常和渠道失败，不混淆报告与邮件状态。
