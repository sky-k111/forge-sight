# U08 完成响应式、可访问性与动效

> 状态：未完成
> 所属大任务：`U前端交互与视觉设计`
> 总体计划：[U00 执行计划](./U00_执行计划.md)

## 执行内容

1. 在 375px、768px、1024px 和 1440px 检查布局。
2. 所有交互可用键盘完成，焦点顺序与视觉顺序一致。
3. 图片有替代文本，图表有文字摘要，状态不只依赖颜色。
4. 正文对比度至少 4.5:1，大文本和非文本 UI 满足相应标准。
5. 动效仅用于面板展开、筛选切换和状态反馈，200～500ms，并尊重 `prefers-reduced-motion`。
6. 表格小屏允许横向滚动，同时保留首要列上下文。

验收：关键页面通过键盘、屏幕阅读语义和对比度检查。
