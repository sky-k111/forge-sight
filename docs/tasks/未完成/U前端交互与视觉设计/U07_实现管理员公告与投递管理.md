# U07 实现管理员公告与投递管理

> 状态：未完成
> 所属大任务：`U前端交互与视觉设计`
> 总体计划：[U00 执行计划](./U00_执行计划.md)

## 执行内容

1. 管理员公告表单包含标题、正文、优先级、接收范围、置顶和有效期。
2. 发布前显示接收人数和影响摘要。
3. 投递管理页按状态、报告/公告、时间和接收人筛选。
4. 展示掩码邮箱、尝试次数、错误原因和下次重试。
5. 手动重发需要明确操作结果，不重复创建业务投递。

验收：业务用户看不到管理写操作，管理员能定位失败任务。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
