# U09 完成浏览器测试与视觉评分

> 状态：未完成
> 所属大任务：`U前端交互与视觉设计`
> 总体计划：[U00 执行计划](./U00_执行计划.md)

## 执行内容

1. 为 API 状态和关键交互补充 Vitest/Testing Library 测试。
2. 在真实浏览器验证邮箱绑定、消息、周报和管理员流程。
3. 检查控制台错误、失败网络请求和重复请求。
4. 对周报首屏、长报告、空状态、数据异常版和移动端截图做视觉检查。
5. 使用 senior-designer Web 检查表逐项评分，所有适用项通过后才交付。

验收：测试与视觉检查均有证据，不能只根据代码推断页面正确。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
