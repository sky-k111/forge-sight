# U03 实现邮箱绑定与验证门禁

> 状态：未完成
> 所属大任务：`U前端交互与视觉设计`
> 总体计划：[U00 执行计划](./U00_执行计划.md)

## 执行内容

1. 登录与注册表单增加明确的邮箱字段和说明。
2. 未验证用户进入专门绑定页，不能看到工作台壳层内容。
3. 验证码输入支持粘贴、倒计时、重发和错误恢复。
4. 更换邮箱说明验证新邮箱前的影响。
5. 按钮使用“发送验证码”“验证并进入工作台”等动宾文案。

验收：新用户和存量用户均能完成流程，错误信息明确且不责怪用户。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
