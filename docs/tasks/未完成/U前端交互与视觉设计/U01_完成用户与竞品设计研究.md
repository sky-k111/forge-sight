# U01 完成用户与竞品设计研究

> 状态：已完成
> 所属大任务：`U前端交互与视觉设计`
> 总体计划：[U00 执行计划](./U00_执行计划.md)

## 执行内容

1. 明确桌面管理层、桌面业务人员和移动端临时阅读三类使用场景。
2. 评估 4～6 个真实产品的报告阅读、指标摘要、订阅消息和异常表格设计。
3. 总结用户已熟悉的行业模式和 ForgeSight 的一个差异点：结论与证据同屏可追溯。
4. 从专业经营简报、制造业控制室信息层级和编辑式年报中选择 2～3 个非模板化视觉参考。
5. 输出研究结论并由产品确认，不直接进入编码。

研究输出：[U01 用户与竞品研究结论](./U01_用户与竞品研究结论.md)

验收：研究明确谁在什么环境中阅读、最先寻找什么信息，以及哪些视觉模式不能照搬。
