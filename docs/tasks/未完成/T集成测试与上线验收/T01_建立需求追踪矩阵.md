# T01 建立需求追踪矩阵

> 状态：已完成
> 所属大任务：`T集成测试与上线验收`
> 总体计划：[T00 执行计划](./T00_执行计划.md)

## 执行内容

1. 将产品需求文档第 17 节每条验收标准映射到自动化测试或人工检查。
2. 标记责任任务、测试层级、环境和证据位置。
3. 对没有验证方式的需求补测试设计。
4. 确认旧阶段六中已被新需求覆盖的审批和飞书主链路不再作为新流程验收。

验收：所有 P0 需求均有唯一责任人和验证证据。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
