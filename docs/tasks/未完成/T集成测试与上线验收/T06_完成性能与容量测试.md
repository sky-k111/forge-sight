# T06 完成性能与容量测试

> 状态：未完成
> 所属大任务：`T集成测试与上线验收`
> 总体计划：[T00 执行计划](./T00_执行计划.md)

## 执行内容

1. 测量典型报告与大报告的 Agent 生成时间。
2. 测量 PDF/Excel 生成时长、内存和文件大小。
3. 测试 100、1,000 和目标规模用户的消息与邮件任务创建。
4. 测试消息列表、未读数和投递管理查询性能。
5. 定义队列积压、失败率和生成时长告警阈值。

验收：形成容量基线和可执行扩容建议，不以开发机单次结果替代。
