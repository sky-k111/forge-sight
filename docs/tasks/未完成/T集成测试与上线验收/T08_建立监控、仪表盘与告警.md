# T08 建立监控、仪表盘与告警

> 状态：已完成
> 所属大任务：`T集成测试与上线验收`
> 总体计划：[T00 执行计划](./T00_执行计划.md)

## 执行内容

1. 监控计划命中率、生成成功率、发布成功率和各阶段耗时。
2. 监控 PDF/Excel 成功率和生成时长。
3. 监控消息创建失败、邮件首次成功率、最终失败率和队列积压。
4. 监控验证码发送异常、频控命中和验证失败率。
5. 告警包含业务 ID 和可操作原因，但不含敏感正文或凭据。

验收：值班人员可以从告警定位到报告、文件或投递记录。
