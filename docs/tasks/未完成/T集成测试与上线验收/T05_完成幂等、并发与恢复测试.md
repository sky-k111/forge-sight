# T05 完成幂等、并发与恢复测试

> 状态：未完成
> 所属大任务：`T集成测试与上线验收`
> 总体计划：[T00 执行计划](./T00_执行计划.md)

## 执行内容

1. 多调度器同时命中同一订阅。
2. 发布事件、文件事件和消息事件重复投递。
3. 多邮件 Worker 同时领取同一任务。
4. Worker 在写结果前后崩溃并恢复。
5. 数据库短暂不可用、邮件限流和文件存储超时。
6. 验证最终只有一个报告版本、一个用户消息和一个业务投递。

验收：所有重试均符合至少一次执行下的业务幂等目标。
