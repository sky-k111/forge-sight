# N03 实现消息列表、未读数与筛选 API

> 状态：未完成
> 所属大任务：`N消息中心与公告`
> 总体计划：[N00 执行计划](./N00_执行计划.md)

## 执行内容

1. 支持全部、周报、公告分类。
2. 支持已读/未读、时间、优先级和关键词筛选。
3. 返回分页游标或稳定分页参数，排序使用置顶、发布时间和 ID 保证稳定。
4. 未读数按当前用户计算，不能接收前端传入任意 ownerId 越权查询。
5. 过期或撤回消息按产品规则展示或隐藏。

验收：用户只能列出自己的消息，分页无重复或遗漏。
