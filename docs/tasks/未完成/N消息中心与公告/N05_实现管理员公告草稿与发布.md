# N05 实现管理员公告草稿与发布

> 状态：实施完成，待合并
> 所属大任务：`N消息中心与公告`
> 总体计划：[N00 执行计划](./N00_执行计划.md)

## 执行内容

1. 只有管理员可创建和修改草稿。
2. 字段校验覆盖标题、正文、优先级、接收范围、置顶和有效期。
3. 发布前计算预计接收人数，管理员确认后冻结公告版本。
4. 公告状态与统一 Outbox 发布事件在同一事务提交，触发站内消息和后续邮件任务。
5. 普通业务用户无法调用管理端写接口。

验收：公告发布后目标用户可见，非目标用户不可见。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
