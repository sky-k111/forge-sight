# N04 实现已读操作

> 状态：未完成
> 所属大任务：`N消息中心与公告`
> 总体计划：[N00 执行计划](./N00_执行计划.md)

## 执行内容

1. 打开消息详情或显式操作时标记当前用户已读。
2. 已读操作幂等，多次调用返回相同结果。
3. 记录首次已读时间，不因重复打开而覆盖。
4. 支持单条已读；“全部已读”可作为后续能力，不阻塞首期。
5. 公告无需确认回执，不建立确认状态。

验收：两个用户对同一消息的已读状态互不影响。
