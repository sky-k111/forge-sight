# N07 实施权限和内容安全

> 状态：实施完成，待合并
> 所属大任务：`N消息中心与公告`
> 总体计划：[N00 执行计划](./N00_执行计划.md)

## 执行内容

1. 周报消息详情再次校验报告和版本权限。
2. 公告接收范围由服务端解析，不信任前端提交的接收人数。
3. 正文输出采用安全渲染策略，禁止注入脚本。
4. 消息摘要不包含用户无权查看的明细。
5. 管理员查询发送结果也遵守管理权限和审计要求。

验收：越权读取、跨用户标记已读和公告脚本注入测试通过。
