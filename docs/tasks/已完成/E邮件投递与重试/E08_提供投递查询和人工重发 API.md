# E08 提供投递查询和人工重发 API

> 状态：已完成
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. 管理员可按报告、公告、接收人、状态和时间筛选投递。
2. 展示掩码邮箱、尝试次数、最后错误、下次重试时间和服务商消息 ID。
3. 只允许对可重试或明确修复后的失败任务重发。
4. 人工重发仍复用原业务投递并增加 attempt，避免新建重复业务记录。
5. 所有人工操作写审计日志。

验收：普通用户无法查看其他人的投递或触发重发。
