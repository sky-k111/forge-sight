# E05 实现错误分类与重试

> 状态：已完成
> 所属大任务：`E邮件投递与重试`
> 总体计划：[E00 执行计划](./E00_执行计划.md)

## 执行内容

1. 区分临时网络错误、限流、服务商 5xx、永久地址错误、附件错误和配置错误。
2. 临时错误默认最多重试 3 次，使用指数退避和随机抖动。
3. 永久错误直接进入 `failed`，不做无意义重试。
4. 配置错误触发管理员告警并暂停批量重试，避免雪崩。
5. 保存每次尝试记录，而不是覆盖最后一次错误。

验收：测试时钟可确定性验证重试时间和上限。
