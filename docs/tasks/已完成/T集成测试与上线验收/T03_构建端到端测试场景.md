# T03 构建端到端测试场景

> 状态：已完成
> 所属大任务：`T集成测试与上线验收`
> 总体计划：[T00 执行计划](./T00_执行计划.md)

## 执行内容

至少覆盖：

1. 新用户注册、验证邮箱、登录和接收周报。
2. 存量用户登录、强制绑定邮箱后进入工作台。
3. 定时任务生成正常周报、自动发布、消息创建、PDF 生成和邮件发送。
4. 关键数据缺失时生成数据异常版周报。
5. 管理员发布公告，目标用户收到站内消息和邮件。
6. PDF 失败、邮件暂时失败、自动重试后成功。
7. 无效邮箱永久失败和管理员手动重发。
8. 新版本替代旧版本，旧邮件仍绑定旧附件。

验收：每个场景包含数据库状态、API 响应、页面表现和渠道结果断言。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
