# T09 制定灰度发布和回滚方案

> 状态：已完成

> 总体计划：[T00 执行计划](./T00_执行计划.md)

## 执行内容

1. 首先只为内部测试用户启用邮箱绑定和自动周报。
2. 按模板、组织或订阅分批放量。
3. 设置调度、邮件 Worker 和强制邮箱门禁独立开关。
4. 明确停止新任务、排空队列、恢复处理和替代错误报告步骤。
5. 数据库回滚不删除新字段和历史事件，应用回滚保持向前兼容。

验收：演练关闭邮件而保留站内发布，以及关闭调度而保留历史读取。
