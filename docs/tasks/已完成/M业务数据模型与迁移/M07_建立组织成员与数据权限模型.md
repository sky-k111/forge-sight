# M07 建立组织成员与数据权限模型

> 状态：已完成
> 所属大任务：`M业务数据模型与迁移`
> 总体计划：[M00 执行计划](./M00_执行计划.md)

## 执行内容

1. 新增 `OrganizationUnit` 表达企业、区域、部门等树形组织节点。
2. 新增 `UserMembership` 表达用户所属组织、岗位和组织内业务角色。
3. 新增 `DataScopePolicy` 表达可访问的数据源、业务维度和值域，并与用户、组织或岗位关联。
4. 认证角色 `business/admin` 只控制平台操作权限，不替代业务组织角色。
5. 提供统一范围解析契约：输入用户和目标业务，输出显式接收资格与可执行数据范围。
6. 为组织层级、成员和策略生效时间建立必要索引和审计字段。

验收：显式用户、角色、部门、区域、岗位接收范围均能解析为用户集合和数据权限，
R、V、N、E 无需自行解释权限 JSON。
