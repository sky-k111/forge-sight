# Q04 增加验证邮件适配边界

> 状态：已完成
> 所属大任务：`Q邮箱绑定与验证`
> 总体计划：[Q00 执行计划](./Q00_执行计划.md)

## 执行内容

1. 定义独立的验证邮件发送接口，不直接耦合具体 SMTP 厂商。
2. 开发环境提供捕获式实现，仅记录任务状态，不输出验证码到生产日志。
3. 配置发件人、邮件服务连接和超时参数，全部来自环境变量。
4. 发送失败时保留挑战并返回可重试状态，不误报验证邮件已发送。
5. 为 E 任务预留统一 `MailProvider` 契约，但不在此实现周报附件。

验收：服务商可替换，测试可使用 fake provider 验证邮件内容和调用次数。

## 完成记录

- 已定义可替换的 `VerificationMailProvider` 和统一 `SendResult`。
- 已提供仅保存在内存中的 capture Provider，验证码不会进入对象日志表示。
- Provider 选择、发件人和超时参数均从环境变量读取。
- 发送成功才增加成功发送次数；失败时保留挑战、记录失败事件并返回可重试错误。
- SMTP 厂商连接和周报附件仍由 E 任务实现，本任务未引入厂商耦合。
