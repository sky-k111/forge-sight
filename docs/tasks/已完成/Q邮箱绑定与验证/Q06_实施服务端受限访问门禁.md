# Q06 实施服务端受限访问门禁

> 状态：已完成
> 所属大任务：`Q邮箱绑定与验证`
> 总体计划：[Q00 执行计划](./Q00_执行计划.md)

## 执行内容

1. 在鉴权依赖中区分完整会话和仅邮箱绑定会话。
2. 默认所有业务、报告、管理接口要求完整会话。
3. 只对白名单接口开放受限会话：`me`、绑定、验证、重发、退出。
4. 防止前端绕过绑定页面直接访问 API。
5. 记录邮箱绑定、变更、验证成功、频控拦截和失败尝试审计事件。

验收：使用未验证 token 调用任意报告接口返回统一的 403 业务错误。

## 完成记录

- token 已包含 `auth_scope`，旧 token 缺少该声明时按 restricted 处理。
- 门禁开启后，匿名业务请求返回 401，restricted 请求统一返回
  `EMAIL_VERIFICATION_REQUIRED`，删除认证头不能绕过。
- 绑定、验证、`/me` 和退出接口保持 restricted 白名单；full token 仍会二次检查数据库验证状态。
- 门禁默认关闭，匿名演示仅受显式 `DEMO_MODE_ENABLED` 控制。
- 门禁与 capture Provider 的危险组合有启动守卫，需显式测试放行。
- 验证码请求、变更、成功、失败和频控均写入只含脱敏邮箱的审计事件。
