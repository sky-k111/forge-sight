# Q03 实现验证码生成、保存和验证服务

> 状态：已完成
> 所属大任务：`Q邮箱绑定与验证`
> 总体计划：[Q00 执行计划](./Q00_执行计划.md)

## 执行内容

1. 使用安全随机源生成六位数字验证码。
2. 数据库仅保存带服务端密钥的哈希，日志不得打印验证码。
3. 默认有效期 10 分钟，重发间隔 60 秒，单挑战错误上限 5 次。
4. 对账号、邮箱和 IP 设置小时级发送限制。
5. 新验证码发出后使同用途旧挑战失效。
6. 成功验证后原子更新用户邮箱和 `email_verified_at`，同时消费挑战。

验收：验证码不可复用，过期、错误次数和频控均有自动化测试。

## 完成记录

- 已实现 ASCII 邮箱规范化、canonical 比较值和脱敏展示。
- 验证码使用安全随机源生成，数据库仅保存服务端密钥 HMAC。
- 已实现 10 分钟有效期、60 秒重发冷却和 5 次错误上限。
- 已实现账号、邮箱和 IP 的滚动小时频控，并写入不可变验证事件。
- 已实现挑战复用与取代，以及验证成功时邮箱更新和挑战消费的同一事务提交。
- 自动化测试覆盖过期、错误上限、频控、邮箱占用竞态和验证码重放。
