# R06 生成摘要、异常与行动建议

> 状态：已完成
> 所属大任务：`R智能生成与自动发布`
> 总体计划：[R00 执行计划](./R00_执行计划.md)

## 执行内容

1. 基于已经验证的结构化章节结果生成管理摘要。
2. 选择 3～5 条有决策价值的发现，过滤小幅噪声和重复结论。
3. 异常按严重程度、影响范围和证据强度排序。
4. 原因字段严格使用已证实、可能相关、待调查三类。
5. 行动建议包含优先级、建议负责人、期限和预期效果，但不自动创建工单。

验收：摘要不包含无证据数字，原因措辞与证据状态一致。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
