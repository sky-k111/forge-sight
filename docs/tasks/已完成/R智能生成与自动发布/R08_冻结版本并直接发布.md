# R08 冻结版本并直接发布

> 状态：已完成
> 所属大任务：`R智能生成与自动发布`
> 总体计划：[R00 执行计划](./R00_执行计划.md)

## 执行内容

1. 在事务中冻结结构化版本、设置发布时间并切换 `current_version_id`。
2. 记录 `publish_source=agent`，不填写伪造的人工审核人。
3. 在同一事务中写入稳定的 Outbox 发布事件，供 V、N、E 至少一次消费。
4. 重试时依据幂等键返回已有成功结果。
5. 重新生成时创建新版本并建立替代关系。

验收：校验通过后自动进入 `published`，不会停留在 `awaiting_review`。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
