# R07 接入自动发布校验门

> 状态：已完成
> 所属大任务：`R智能生成与自动发布`
> 总体计划：[R00 执行计划](./R00_执行计划.md)

## 执行内容

1. 调用 V 定义的确定性校验器。
2. 硬校验失败进入 `validation_failed`，不得发布正常周报。
3. 软校验失败降低可信度并写入醒目限制说明。
4. 关键数据不足时构建数据异常版周报。
5. 保存全部校验结果和工作流版本。

验收：不存在“LLM 自己认为正确就发布”的路径。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
