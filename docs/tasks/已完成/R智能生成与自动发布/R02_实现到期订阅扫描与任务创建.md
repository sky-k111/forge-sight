# R02 实现到期订阅扫描与任务创建

> 状态：已完成
> 所属大任务：`R智能生成与自动发布`
> 总体计划：[R00 执行计划](./R00_执行计划.md)

## 执行内容

1. 扫描 `enabled` 且 `next_run_at <= now` 的订阅。
2. 使用数据库锁或唯一约束避免多 Worker 重复创建。
3. 创建报告业务身份和生成任务后，原子更新下次运行时间。
4. 失败时不跳过当前周期，保留可补偿状态。
5. 记录计划命中、跳过、补偿和禁用原因。

验收：重启进程后未完成任务能够恢复，漏跑周期能够补偿一次。

## 提交要求

- 实现范围只覆盖本小任务及其必要测试，超出范围的工作回填到对应任务文件。
- PR 描述必须关联本任务编号，并写明依赖、数据或接口变化以及验证结果。
- 完成后将本文件的状态改为“已完成”，再随大任务一起迁移到 `docs/tasks/已完成`。
