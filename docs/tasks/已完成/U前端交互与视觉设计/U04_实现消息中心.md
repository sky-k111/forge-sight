# U04 实现消息中心

> 状态：已完成
> 所属大任务：`U前端交互与视觉设计`
> 总体计划：[U00 执行计划](./U00_执行计划.md)

## 执行内容

1. 在全局导航提供消息入口和未读数。
2. 页面提供全部、Agent 周报、管理员公告分类。
3. 支持已读/未读、时间和重要程度筛选。
4. 消息行展示来源、标题、两行摘要、时间、状态和主操作。
5. 打开详情后调用已读 API，未读数即时更新并能在失败时恢复。
6. 空状态说明当前没有哪类消息，不使用通用空盒子插画。

验收：用户可以在不打开每条消息的情况下判断优先级和下一步。
