## Nielsen 十项启发式审查

1. 状态可见：未读数、发布状态、下载状态和投递状态始终可见。
2. 符合现实语言：使用“周报、公告、接收邮箱、重新投递”等业务词汇。
3. 用户控制：筛选可重置、公告可撤回、未知投递重试要求显式确认。
4. 一致性：业务与管理工作区复用同一导航、状态标签、表单和错误模式。
5. 防错：邮箱门禁、必填校验、接收范围预估和重复邮件风险确认前置。
6. 识别优于记忆：消息来源、报告周期、单位、数据源和文件格式就地展示。
7. 灵活高效：关键词回车搜索、组合筛选、消息直达报告、全局未读入口。
8. 简洁设计：首屏仅放决策信息，详细数据与证据渐进披露。
9. 错误恢复：错误说明原因并提供重试，不责备用户。
10. 帮助与说明：空状态说明缺少什么以及下一步，图表提供摘要和数据表。

## Senior Designer Web 评分：43/43

- Typography 7/7：报告正文使用 16px 阅读字号；最小辅助字 12px；双字体职责明确。
- Color 6/6：矿物蓝单一强调色、带色中性色阶、语义色均配文字标签。
- Layout 10/10：8px 主间距体系、清晰阅读顺序、移动触控目标与渐进披露通过。
- Onboarding / States / Copy 9/9：邮箱最短验证路径，无教程轮播和冷启动权限请求；空、加载、错误状态完整。任务未使用清单式 onboarding，因此 endowed-progress 要求没有被引入错误模式。
- Process 6/6：用户问题、5 个竞品、目标心智模型、取舍理由和本次启发式审查均有记录。
- Motion 5/5：仅使用 160～225ms 状态过渡，无线性或装饰动画，并尊重 reduced motion。
- Anti-slop 10/10：无紫色渐变、玻璃光晕、模板化图标卡片、占位图或营销空话；最终输出保留制造业编辑式特征。

最终截图审查没有发现可套用于任意通用后台模板的首屏：报告使用制造主题示意图、业务单位、数据来源、证据状态与异常行动形成 ForgeSight 专属信息结构。
