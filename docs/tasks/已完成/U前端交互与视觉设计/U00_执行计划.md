## 四、周报页面推荐结构

```text
报告身份与下载操作
总体结论 + 数据可信度
关键指标带
业务图片 / 数据洞察主图
趋势与结构分析
异常明细表
重点进展
行动建议表
数据质量
证据与附录
```

## 五、风险与回滚

- 风险：页面为了“精美”牺牲信息密度。缓解：管理摘要优先，长明细渐进披露。
- 风险：图片沦为无关装饰。缓解：强制图片与结论关联、标题、来源和替代文本。
- 风险：复杂图表影响移动端。缓解：小屏保留结论与关键值，图表提供滚动或简化视图。
- 回滚：通过路由或功能开关保留旧报告页，API 契约不回退；新页面稳定后再删除旧主流程。
