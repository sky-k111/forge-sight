# V07 实现鉴权下载 API

> 状态：已完成
> 所属大任务：`V版本管理与文件导出`
> 总体计划：[V00 执行计划](./V00_执行计划.md)

## 执行内容

1. 使用 `report_id + format` 或 `file_id` 获取文件，不暴露内部存储 URI。
2. 校验登录、消息接收关系、报告权限和数据范围。
3. 返回正确 `Content-Type`、安全文件名和下载头。
4. 对未就绪文件返回明确状态，对失败文件返回可诊断错误。
5. 记录下载审计，不在日志记录敏感正文。

验收：未登录、非接收人和越权用户均无法下载。
