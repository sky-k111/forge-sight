# 可信 Agent 运行链路改造状态

日期：2026-09-09。分支：codex/trusted-agent-runtime-20260909。

## 已接入的改动

- AgentIntent 的结构化子任务保留独立指标、时间、维度、图表和 requirementId；LLM 路径不再使用关键词拆分替换这些任务。
- Planner 不得遗漏原始查询需求，匹配的需求使用原始任务参数；未覆盖时退回确定性计划。
- 比较周期以一个比较查询交付，多时间区间用 OR 连接，不把间隔月份纳入比较。
- 时间参考支持 now 与 data_horizon 区分；修复上一季度和第四季度跨年边界。
- 明确绝对时间范围不再被 data_horizon 二次解析覆盖；“上个月”可分别以系统日期或数据截止日为基准。
- 查询需求在执行前冻结为统一绑定契约：指标、事实表、分组、跨表筛选、排序和 TopN 均绑定到物理资源；SQL AST 同时核对字段血缘、筛选值、排序方向、数量限制和日/周/月/季/年分桶粒度。
- 编译器产出结果字段角色，图表消费时间维度与度量角色，降低按列值猜测的影响。
- 意图解析提供 JSON Schema、结构化输出模式和带错误原因的修复提示；服务失败不再伪装为用户未说明需求。
- 模型客户端连接复用，SDK 隐式重试关闭；不支持 JSON mode 的 OpenAI 兼容供应商会协商降级到普通文本，再由上层 Schema 校验。
- 每次 active execution 应用总截止时间，LLM 调用超时会按本轮剩余预算缩短；恢复 checkpoint 时使用本轮进程内单调时钟，不复用旧进程时间戳。节点间检查取消/截止状态，数据库还有连接器级语句超时。
- 独立 request requirement ledger 在规划前冻结；快速路径、Planner、查询、图表、报告和建模均按账本验收，部分完成明确披露。
- 多结果快照按结果保存意图、任务、SQL、口径和展示契约；歧义追问要求选择结果 ID。
- 柱状图/折线图展示调整直接复用已验收结果；单系列类目轴可无损转环形图，不重新检索元数据或执行 SQL。
- 前端移除未校准百分比，显示“分析质量检查”；交付账本支持逐项状态、部分交付结果及建模提案。
- 确定性查询编译已把时间分桶和限行下沉至连接器，覆盖 MySQL/MariaDB、PostgreSQL、SQL Server 和 Oracle；新连接器可独立实现。
- 查询绑定契约同时冻结指标、事实表、维度与筛选物理字段、所属表及已登记 Join 路径，并作为独立证据产物持久化。确定性编译可生成已登记外键路径上的 Join；未登记关系时安全回退，不把维表字段错当事实表字段。
- 确定性编译与模型生成 SQL 都在验证阶段产出结果字段角色，图表直接消费该角色契约，不再依赖列名猜测主横轴与度量。
- 正式部署默认启用 AgentIntent 结构化主路径；旧语义规则只在模型不可用或契约解析失败时降级使用，示例环境文件也显式声明该开关。

## 尚未完成的验收及限制

本次不是整套最终方案已经完成。还需要：

1. 用真实模型、真实数据源回放截图问题，测量正确率和 P50/P95 延迟。
2. 主路径已由 AgentIntent 和绑定契约驱动；旧正则仅作功能开关关闭/模型不可用时的兼容降级和安全边界，不应继续承担新语义。
3. Python 同步调用无法在运行中途强杀；当前依靠剩余预算约束的 HTTP 超时、数据库语句超时、节点间总截止时间和取消检查。若要毫秒级硬取消，需要把调用迁移到可取消的异步任务/子进程边界。
4. 已登记外键关系支持确定性单跳和多跳 Join；未登记关系、需要业务桥接规则的多对多关系仍回退到受治理 SQL 路径，不能擅自假设连接口径。
5. 散点图、热力图、组合图之间不是无损语义转换，展示追问仍会重新进入受治理分析路径，而不是强行复用造成误导。
6. 真实模型/真实数据回放仍需明确授权向外部模型服务发送本项目的意图解析上下文；本轮未进行外发。

现有能力注册表和治理子图继续承担报告、建模、监控及审批扩展，不另造一套业务实现；不放宽只读、租户隔离、白名单和审批边界。
