智能异常监控

业务服务

![Slide 1 Image 3](final_readback_files/image_75bf3d8d6384c1b0.png)

异常出现后通知责任人，呈现趋势、样本量、

数据截至时间与恢复状态。

底层实现

规则绑定：从受控模板选字段，验证后发布。

1

周期评估：只读查询，以确定性规则判断。

2

状态与投递：留存证据，记录触发、持续、

3
