## 需求优先级

本目录中的决策优先于 `docs/phase-6-reports/PHASE6_WEEKLY_REPORT_RESEARCH_AND_DESIGN.md` 中与以下事项冲突的旧设计：

1. 周报改为 Agent 校验通过后直接发布，不再经过业务人员人工复核。
2. 第一外部触达渠道改为用户绑定邮箱，不再以飞书群机器人作为首期主渠道。
3. 周报发布后同时生成站内消息，邮件固定包含摘要、安全链接和 PDF 附件。
4. 用户必须绑定并验证任意有效邮箱后才能正常进入工作台。

既有阶段六文档中的指标口径、证据链、数据源隔离和不可变版本原则继续有效。
