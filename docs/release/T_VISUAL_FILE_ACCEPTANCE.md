# T 视觉与文件质量验收

<!-- markdownlint-disable MD013 -->

## Web

在真实 Chromium 中以 375×812 与 1440×900 检查周报详情、消息中心、邮箱绑定和管理员投递页：无水平溢出，移动端筛选与卡片自然换行，桌面端信息层级、图表、表格和风险语义清晰。控制台除 React 开发提示外无错误，核心 API 返回 200。

周报验收重点：首屏先给一句话结论和最高风险；指标值/上期值/环比同屏；趋势图带单位、来源和可访问摘要；异常、行动、进展、数据质量及证据逐层展开；图片带替代文本。

## PDF

- 典型周报 2 页，长表样例 7 页；使用独立 PDF 渲染器逐页转图检查。
- 中文可检索，标题、图表、异常表、行动表无截断或重叠；长表重复表头，最后一行可检索。
- 用户文本进行 ReportLab 标记转义，不允许本地文件标签被嵌入。

## Excel

- 使用桌面版 Microsoft Excel 只读打开并导出预览。
- 4 个工作表：指标概览、异常明细、行动建议、数据来源与口径；数字为真实数值类型，百分比/日期有格式，A6 冻结表头。
- 发现并修复日期显示 `########`：周期日期改为 `yyyy-mm-dd`，所有工作表设置横向、单页宽度和重复标题行。
- 不可信文本进行公式注入中和，权限范围来自同一冻结版本。

本地验收样例位于忽略目录 `output/release-t/`，不提交业务数据或二进制验收产物。
